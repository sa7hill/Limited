# Cash Payment Limited — starter website

A responsive, single-page front-end demo.

## Run
Open `index.html` in a browser. No build tools required.

## Before accepting real payments
- This project does not process payments, verify UTRs, store data, or provide authentication.
- Replace the QR placeholder with a QR issued for your own verified merchant UPI account.
- Integrate a regulated payment gateway and server-side verification/webhooks.
- Add secure authentication, database, validation, privacy notice, and admin review.
- Use “Limited” only if the legal entity is registered under that name; check name availability and applicable requirements first.
